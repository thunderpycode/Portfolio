# Abhishek Srivastava — SRE / DevOps Portfolio

A playful, responsive portfolio built with plain HTML, CSS and JavaScript. It has no build step or dependencies, so GitHub Pages can serve it directly.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch to publish (usually `main`) and the `/ (root)` folder, then save.
5. GitHub Pages will provide the published URL in the Pages settings.

The contact details and profile links come from the supplied résumé. The graphical dashboard is illustrative; the reductions shown are résumé-backed results, and the uptime/vibes display is intentionally a joke rather than a service-level claim.
